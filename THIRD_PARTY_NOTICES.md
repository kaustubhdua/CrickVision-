# Third-party notices

CrickVision's initial baseline uses:
- PyTorch / Torchvision, including Torchvision's COCO-pretrained Faster R-CNN ResNet-50 FPN weights.
- OpenCV for video decoding and annotation.
- Pillow for image conversion.

Review the exact licence and redistribution terms for each installed package, pretrained checkpoint, dataset, and input video before redistribution or commercial use. The project does not bundle video footage or model weights. See the official upstream project documentation for current terms.
